# Лес Эхо: Пробуждение

Небольшая браузерная кооперативная RPG на Python/FastAPI. Девять земель существуют как отдельные карты: у каждой свои жители, лавка, ремесленник, ресурсы, противники и поручение. Сервер отвечает за движение, бой, торговлю, переходы и сохранение персонажей; браузер отрисовывает мир и передаёт действия игрока.

## Девять отдельных земель

Каждая карта имеет локальную систему координат размером **2000 × 1500**. В начале карты расположены безопасная стоянка, местный хранитель истории, торговец и мастер. Дальше — ресурсы, места силы, противники и достопримечательности региона.

| Глава | Регион | Рекомендуемый уровень | Лавка |
| --- | --- | --- | --- |
| I | Лагерь Следопытов | Безопасная зона | «Тёплый костёр» |
| II | Шепчущий лес | 1–3 | «Лисий хвост» |
| III | Затонувшие топи | 4–6 | «Чёрная вода» |
| IV | Пепельные руины | 7–10 | «Последний жар» |
| V | Хребет Синего Пламени | 11–14 | «Синий иней» |
| VI | Разлом Эха | 15–19 | «Седьмая грань» |
| VII | Астральная Бездна | 20–25 | «Падающая звезда» |
| VIII | Обсидиановый край | 26–30 | «Чёрное зеркало» |
| IX | Первозданный сад | 31–35 | «Первый рассвет» |

Рекомендуемый уровень — ориентир сложности. Для перехода через дорожный камень сервер проверяет минимальный уровень следующей земли.

### Жители, торговля и поручения

- **28 именных НПС**: на каждой карте хранитель истории, торговец и мастер; в лагере также есть отдельный чародей.
- **Девять отдельных ассортиментов**, по шесть позиций в каждой лавке. Купить товар другой земли или торговать на расстоянии нельзя.
- **Местные поручения**: сбор материалов и/или победа над противниками этой карты. Прогресс засчитывается после принятия задания; материалы для сдачи должны оставаться в рюкзаке. Награду нельзя получить повторно.
- **Кузницы и мастера чар** привязаны к местным НПС. Изготовление, улучшение и зачарование доступны рядом с мастером, предоставляющим соответствующую услугу.
- Основная сюжетная цепочка из **13 этапов** по-прежнему начинается у Егора Хранителя в лагере.

### Путешествия

**Атлас** открывается клавишей **M**, кнопкой «Атлас» или через меню. Он показывает земли, требования к уровню, местных жителей, лавки и маршрут. Кнопка выбора земли не телепортирует персонажа сама по себе: нужно дойти до дорожного камня.

- **16 двусторонних переходов** соединяют соседние земли.
- Для перехода нужно находиться рядом с камнем, соответствовать уровню назначения и быть вне боя.
- После последнего боевого действия действует шестисекундная задержка перед путешествием.
- Возвращение в лагерь доступно вне боя; повторное использование восстанавливается за 20 секунд.
- При переходе снимаются старые снаряды и эффекты перемещённого игрока, очищается сбор ресурсов и сохраняется персонаж.

Игроки, противники, ресурсы и боевые события одной карты изолированы от других. Урон и PvP не проходят между картами. Безопасные стоянки и дорожные камни защищают от PvP. После поражения персонаж возвращается в лагерь, сохраняя добычу.

## Запуск

Нужен **Python 3.10 или новее**.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

На компьютере-хосте откройте **http://localhost:8000**. Друг подключается к `http://ЛОКАЛЬНЫЙ_IP_ХОСТА:8000`; разрешите входящие подключения в брандмауэре. Сервер слушает `0.0.0.0:8000` и поддерживает до восьми игроков одновременно.

Для доступа через интернет настройте HTTPS и контроль доступа самостоятельно. Не публикуйте порт напрямую без защиты. Все участники должны подключаться к одной копии сервера.

## Аккаунты и сохранения

При первом входе выберите «Регистрация», задайте имя и пароль от восьми символов. Для следующих входов используйте «Вход».

- Пароли хранятся как PBKDF2-HMAC-SHA256 с индивидуальной солью, не открытым текстом.
- Сессия хранится в HTTP-only cookie; на HTTPS она получает флаг Secure. Кнопка «Выйти» отзывает сессию.
- Аккаунты и персонажи сохраняются в **`echo_saves.sqlite3`** рядом с сервером. Делайте резервную копию этого файла. Восстановления пароля по почте нет.
- Сохраняются регион, посещённые земли, региональные и сюжетные поручения, уровень, характеристики, снаряжение, улучшения, зачарования и магия.
- Старые сохранения с единой карты автоматически переносятся в соответствующий регион, в безопасную точку появления. Уровень, предметы и прогресс сохраняются.

## Управление

| Действие | Клавиша / управление |
| --- | --- |
| Движение | WASD / стрелки; физическая раскладка клавиш |
| Атака | Удерживать левую кнопку мыши, отпустить для удара; пробел |
| Направление атаки | Положение указателя мыши |
| Ближайший житель, камень или ресурс | F / контекстная кнопка |
| Сбор ресурса | E |
| Местная лавка | B, находясь рядом с торговцем |
| Настойка здоровья | Q |
| Бег | Удерживать Shift (тратит выносливость) |
| Подкрадывание | Удерживать Ctrl (медленно, мобы замечают позже) |
| Рывок | V |
| Инвентарь | I |
| Атлас девяти земель | M |
| Чат | Enter |
| Заклинания | **Shift** + цифра 1–9; Shift+0 и F1–F12 — созданные заклинания, назначение настраивается |
| Быстрые слоты инвентаря | Цифры 1–9 без Shift (зелья и расходники) |
| Способности класса | Отдельная клавиша у каждой: воин — K/P/O/L, стрелок — K/P/O/N/L, маг — R/T/P/X/O/N/K/L |
| Звук (вкл/выкл) | Z или кнопка динамика у правого края |
| Закрыть верхнее меню | Escape |

На сенсорных устройствах движение и боевые действия доступны через меню «Управление». Игровые горячие клавиши и движение отключаются при открытом меню или вводе текста. Персонажи продолжают существовать в общем мире, пока их меню открыто.

## Звук и анимации

Звуковое сопровождение синтезируется в браузере через WebAudio: отдельных аудиофайлов нет, поэтому всё вместе занимает несколько килобайт и не грузится по сети. Оно намеренно разреженное — тихий ветер с редкими птицами, шаги в такт движению, короткие отклики на удар, выстрел, заклинание, лечение, добычу и повышение уровня. Мастер-гейн проходит через лимитер, поэтому резкие звуки не «клиппят».

- Звук включается только после первого действия игрока: браузеры не разрешают автоплей.
- Переключатель — кнопка динамика у правого края экрана или клавиша **Z**; выбор запоминается в `localStorage`.
- Вкладка в фоне усыпляет контекст, при возврате он продолжается без щелчка.

Боевые анимации получили вес: короткая остановка кадра (hit-stop) и толчок камеры на попадании, толстый серп удара с белой ведущей кромкой, ударная волна с пылью, руны и восходящие искры у заклинаний, столб света при новом уровне, след стрелы и шлейф после рывка. Все эффекты рисуются тем же пиксельным рендерером и не меняют симуляцию: сервер по-прежнему решает исход боя.

Плавность движения, камеры и частиц зависит от прошедшего времени, поэтому частота экрана не меняет скорость анимации. Hit-stop запускается рядом с героем не чаще раза в 250 мс и не продлевается потоком попаданий союзников. Истёкшие боевые эффекты удаляются; пул частиц ограничен 400 элементами и очищает устаревшие вспышки после возврата во вкладку.

## Бой, экипировка и магия

Сохранены заряжаемые удары, оружие ближнего и дальнего боя, классовые способности, базовые заклинания и создание собственных заклинаний из изученных стихий. Характеристики, мастерство оружия и магии, расход маны и развитие персонажа подтверждаются сервером.

Заклинания и мастерская их сплетения доступны Магу с посохом. Индикатор заряда оружия учитывает скорость атаки от экипировки и перековки. Попытка выстрелить с пустым колчаном сохраняет выносливость, комбо и подготовленную контратаку. Крит посоха определяется при выпуске снаряда, а стихийные стрелы участвуют в реакциях при попадании.

Монстры сначала готовят удар. На земле видна его форма и направление: уклонись из подсвеченной области до конца обратного отсчёта. Выпад вепря и атаки боссов нельзя переждать рядом: рывок за пределы размеченной зоны избегает попадания. Боссы меняют скорость и набор приёмов на отметках 66% и 33% здоровья; полоса над противником показывает его нарастающую стойкость и момент её слома. Воины могут парировать первые 0,22 секунды удара способностью «Железная стойка» — монстр оглушается, и открывается контратака. Удар в спину наносит на 30% больше урона. Уклонение из настоящего замаха отменяет заряд игрока и тоже открывает контратаку.

Приближаясь к боссу, ищи приём и текущую фазу в верхней панели. После промаха монстра возникает окно для ответного удара. Подсказки в бою напоминают, когда выйти из размеченной зоны, вылечиться, восстановить выносливость или атаковать оглушённую цель. Полный краткий учебник доступен в разделе «Управление и заклинания».

Заклинания отделены от быстрых слотов: цифра без Shift пьёт расходник из инвентаря, **Shift**+цифра выпускает заклинание. Так один и тот же ряд клавиш не приходится переназначать между магией и зельями.

### Полевой бестиарий

Открой **Esc → Бестиарий** или кнопку «Бестиарий» в панели управления. Дневник охватывает 21 вид: поиск, фильтры по землям и прогрессу, портреты, история, базовые характеристики, тактика против настоящих приёмов и подсказки о возможной добыче. Характеристики врага растут с его уровнем. До первой засчитанной победы видны только силуэт и места обитания.

Одна победа открывает запись, пять дают ранг «Изучено», пятнадцать — «Мастерство охоты». Это ранги коллекции. Засчитанные участники совместного боя получают собственный прогресс; он сохраняется между входами. Старые записи о победах над боссами открывают их страницы, а история обычных монстров начинается с новых побед.

После смерти противника остаётся короткое цветное эхо. Участники победы над боссом или мини-боссом видят его имя в баннере и слышат короткий аккорд. Эффекты используют существующий ограниченный пул, исчезают по реальному времени, очищаются при путешествии и учитывают уменьшение анимации.

### Способности мага

У мага восемь способностей, и все они тратят **ману**, а не выносливость. Они открываются по мастерству магии, требуют посох и стоят на своих клавишах; описание и цена видны на карточке панели способностей.

| Способность | Клавиша | Мана | Что делает |
| --- | --- | --- | --- |
| Чародейская стрела | R | 10 | Быстрый снаряд стихии «Аркана» в точку прицела; дешёвый и с коротким откатом |
| Ледяное копьё | T | 14 | Пробивающий снаряд; замедляет цель на 3.5 с до 45 % скорости |
| Пламенный всплеск | P | 18 | Взрыв в точке прицела, поджигает задетых на 4 с |
| Цепная молния | X | 20 | Прыгает по трём целям поблизости, урон падает на каждой (×0.78) |
| Мерцание | O | 12 | Рывок-телепорт на 190 единиц сквозь толпу |
| Чародейский щит | N | 16 | На 6 с прибавляет 12 брони |
| Прилив маны | K | 0 | Возвращает 28 маны; откат 18 с |
| Падение метеора | L | 30 | Тяжёлый удар по площади с поджогом на 3 с |

Панель способностей мага поднимается над рядом заклинаний, чтобы обе панели оставались видны, а карточки показывают ману вместо выносливости.

- Оружие и броню можно улучшать в кузнице до **+15**, аксессуары — до **+10**; успех зависит от уровня улучшения. Стоимость попытки списывается и при неудаче.
- Мастера чар накладывают зачарования на принадлежащие персонажу предметы. Помимо монет требуются эхо-кристаллы; цена растёт с уровнем зачарования.
- Созданным заклинаниям можно назначать клавиши; рецепты и мастерство сохраняются в профиле. Названия разбираются локальным словарём стихий, без обращения к внешней модели.
- Места силы ускоряют восстановление здоровья, маны и выносливости. В лагере бонус выше.
- В поздних землях ждут сильные противники и боссы; победы над боссами учитываются в прогрессе персонажа.

## Оформление и устройство клиента

Террейн каждой карты строится из общего описания региона и кэшируется отдельно: дороги, стоянка, торговая точка, мастерская, ориентиры, арена босса и биомный декор. Погода меняется от лесных листьев и болотного тумана до снега, рун и лепестков. Камера ограничена границами текущей карты.

Добавлены региональный HUD, подсказки взаимодействия, диалоги с портретами НПС, баннеры путешествий, поиск и фильтры товаров. Интерфейс адаптируется к небольшим экранам и учитывает настройку уменьшения анимации.

- `world.py` — авторитетные карты, НПС, порталы, население и миграция позиций.
- `server.py` — аккаунты, сохранения, симуляция и проверка действий.
- `static/index.html` — разметка страницы.
- `static/game.js`, `static/game.css` — базовая игра и интерфейс.
- `static/world.js`, `static/world.css` — региональный мир, атлас, НПС и лавки.
- `static/map-events.js` — фильтрация сетевых событий по текущей карте.
- `static/render.js` — пиксельная камера, спрайты, боевые эффекты и hit-stop.
- `static/audio.js` — процедурный звук и переключатель громкости.
- `bestiary.py`, `static/bestiary.js`, `static/bestiary.css` — каталог, история охоты и полевой дневник.

## Проверки

Для автоматических тестов дополнительно установите pytest и HTTPX:

```bash
python -m pip install pytest httpx
python -m pytest tests/ -q
```

Тесты используют временную SQLite-базу и проверяют состав регионов, двусторонние порталы, миграцию старых сохранений, изоляцию снапшотов, приватность чужого инвентаря, переходы и боевые ограничения, местную торговлю, выполнение поручений, защиту от межрегионального урона, безопасные зоны и сохранение региона.

Для проверки синтаксиса при наличии Node.js:

```bash
node --check static/game.js
node --check static/world.js
node --check static/map-events.js
node --check static/render.js
node --check static/audio.js
node --test tests/map_events.test.js
node --test tests/render.test.js
node --test tests/audio.test.js
node --test tests/audio_graph.test.js
```
