# Лес Эхо: Пробуждение — локальная кооперативная RPG

Пиксельная браузерная RPG на Python/FastAPI для игры по локальной сети. Сервер ведёт общий мир, монстров, ресурсы, экипировку, сохранения персонажей и чат.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

На компьютере-хосте откройте http://localhost:8000. Друг подключается к `http://ЛОКАЛЬНЫЙ_IP_ХОСТА:8000` (например, адрес из `ipconfig` в Windows). Разрешите Python входящие подключения в брандмауэре. Сервер слушает все сетевые интерфейсы; для игры через интернет нужны отдельный VPN или настроенный туннель.

Персонаж сохраняется в SQLite-файл `echo_saves.sqlite3` рядом с сервером. Используйте разные имена персонажей для разных игроков.

## Управление

- WASD / стрелки — движение.
- Левая кнопка мыши — удерживать для замаха, отпустить для удара. На мобильном — удерживать кнопку «Атака».
- Наведение мыши задаёт направление удара. Пробел тоже запускает замах.
- E — собирать ресурс поблизости; F — говорить с Хранителем; Q — выпить настойку.
- Shift — уклонение; I — инвентарь; M — большая карта; Enter — чат.
- 1–4 — быстрый выбор базового оружия.

## Содержимое

Шесть регионов возрастающей сложности: лагерь, лес, топи, руины, Хребет Синего Пламени и Разлом Эха. В дальних землях ждут ледяные змеи, рыцари разлома и финальный босс — Дракон Пустого Эха; с них выпадают новые легендарные доспехи и оружие.

Большая карта открывается клавишей M и показывает регионы, дорогу, мобов, ресурсы и игроков. Инвентарь обновляется по состоянию сервера; кнопка экипировки отправляет команду и сервер подтверждает результат в чате/уведомлении.

PvP доступно только вне безопасного лагеря. Игроки получают сниженный урон с учётом защиты; при нуле здоровья персонаж возвращается в лагерь через пять секунд. Безопасная зона блокирует и ближние атаки по игрокам, и стрелы.

## Заметка

Для корректной игры всех участников должна обслуживать одна копия `server.py`. Не публикуйте порт напрямую в интернет без настройки доступа и защиты.


## Последнее обновление: торговля и Зеркальный Предел

- В лагере открой лавку клавишей **B** или кнопкой «Лавка». Можно покупать припасы, продавать ресурсы, неэкипированное оружие и броню из рюкзака. Надетое оружие и доспехи от продажи защищены.
- Мастер чар усиливает оружие рунами «Острота», «Поборник боссов», «Похищение жизни», а броню — «Защитой». Уровни чар покупаются за монеты и эхо-кристаллы; стоимость растёт с уровнем.
- Портальные круги отмечены на карте. Подойди и нажми **F** или кнопку «E · Сбор / F · Лавка», чтобы переключиться между Явью и Зеркальным Пределом. В отражённом мире есть отдельные противники и боссы.
- В Шепчущем лесу и Затонувших топях появились Терновый охотник и Матерь топи; в Зеркальном Пределе — Зеркальный призрак и Титан Междумирья. Боссы имеют собственные дропы и награды.
- Движение распознаёт физические клавиши WASD по коду клавиши, поэтому работает при русской раскладке ЦФЫВ. **F** по-прежнему взаимодействует с Хранителем, **B** открывает торговлю.
- Персонаж, монеты, инвентарь, измерение и зачарования сохраняются в локальной базе SQLite.

Зачарования и торговля проверяются сервером: клиент не может самостоятельно назначить цену, списать предмет или зачаровать вещь вне лагерной лавки.
